# Farben

Die verbindliche Farbpalette dieser Website ist zentral in `app/globals.css` als CSS-Variablen hinterlegt.

| Name | Hex | Einsatz |
| --- | --- | --- |
| Leinen | `#F3EDE3` | Grundfläche aller Seiten; helle Schrift auf dunklem Grund |
| Helles Salbei | `#E4E0CC` | Ruhige Flächen, etwa Textfelder im Einstieg und Kundenstimmen |
| Tannengrün | `#1F3A35` | Dunkle Flächen, etwa bei „Wirklich deins“, Abschlüssen und „Was will ich?“ |
| Warmes Dunkelbraun | `#2E201A` | Schrift auf hellem Grund; Hintergrund des Seiten-Footers |
| Rot-Orange | `#C24426` | Akzent: Hauptbuttons, ein betontes Wort pro Überschrift, kleine Punkte und Linien |
| Senfgold | `#D9A02B` | Akzent auf dunklem Grund: Betonungen, Links und Buttons auf Tannengrün |

## Regeln

- Pro Überschrift höchstens ein farbiges Wort.
- Rot-Orange und Senfgold sind Akzente, keine großflächigen Hintergründe.
- Senfgold wird nur auf dunklem Grund eingesetzt.
- Auf hellem Grund ist Schrift `#2E201A`; auf dunklem Grund `#F3EDE3`.
