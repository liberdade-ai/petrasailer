# Petra Sailer

Die öffentliche Website von Petra Sailer ist eine vollständig statisch
exportierte Next.js-App-Router-Anwendung für Netlify.

## Entwicklung

```bash
npm install
npm run dev
```

`npm run build` erzeugt die deploybaren HTML-, CSS-, JavaScript- und Bilddateien
in `out/`. Netlify veröffentlicht diesen Ordner direkt.
